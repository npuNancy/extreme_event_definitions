# 场站位置与网格数据对应方式代码修改计划

## 1. 背景

当前场站级流程对一个场站使用最近邻网格点获取气象或容量因子数据：

1. `regional_bcsd`、`china_cmfd_bcsd` 等规则经纬度网格使用一维 `lat/lon` 最近邻。
2. `cordex_nam12` 旋转极网格使用二维真实 `lat/lon` 展平后的最近邻。
3. Pipeline B 输出属性记录 `match_method = nearest` 和 `max_match_dist_deg`。
4. 低资源事件中，目标 SSP CF 目前仍沿用最近邻；ERA5Land 稀疏阈值预计算已对阈值侧使用四点双线性。

这个计划只讨论后续如何统一“场站位置 -> 网格数据”的映射方式，不在本步骤改代码。

## 2. 目标

1. 为不同数据源提供显式、可配置、可记录的空间映射方式。
2. 保持默认行为与当前结果兼容，即默认仍为最近邻。
3. 支持规则经纬度网格的双线性插值。
4. 为 NAM-12 等二维网格保留最近邻，并预留更复杂插值方案。
5. 输出文件必须记录实际使用的映射方法、距离或权重信息，避免后续结果不可追踪。

## 3. 可选映射方式

### 3.1 最近邻

名称：

```text
nearest
```

适用：

1. 所有数据源。
2. 规则经纬度网格。
3. 旋转极或不规则二维网格。

优点：

1. 当前实现已验证。
2. 不会混合陆海、山地和平原等相邻格点。
3. 适合场站本来已经落在模型网格中心附近的输入。

缺点：

1. 对站点位于两个网格中间的情况不连续。
2. 对粗分辨率网格可能有位置误差。

### 3.2 双线性插值

名称：

```text
bilinear
```

适用：

1. 一维规则经纬度网格，例如 ERA5Land、BCSD、CMFD-BCSD。
2. 经度需要支持 `[0, 360)`、`[-180, 180)` 和接缝环形距离。

优点：

1. 空间变化连续。
2. 对场站不在网格中心的情况更合理。
3. 与当前 ERA5Land 稀疏阈值四点权重思路一致。

缺点：

1. 会混合四个格点，可能跨海陆或地形突变边界。
2. 对缺测格点需要定义权重重归一规则。
3. 对旋转极二维网格不能直接使用一维 `lat/lon` 公式。

### 3.3 反距离权重

名称：

```text
idw
```

适用：

1. 二维经纬度辅助坐标网格。
2. 规则网格也可使用，但不是首选。

建议初始策略：

1. 使用 KDTree 查找最近 `k=4` 或 `k=8` 个网格点。
2. 权重为 `1 / distance^p`，默认 `p=2`。
3. 距离为 0 时退化为单点权重 1。

优点：

1. 可用于 NAM-12 旋转极网格。
2. 实现复杂度低于真正的二维网格单元定位。

缺点：

1. 不保证严格落在包围场站的网格单元内。
2. 对不规则网格边界附近可能偏向点密集方向。

### 3.4 网格单元覆盖或保守映射

名称：

```text
conservative
```

适用：

1. 面状场站或区域聚合。
2. 后续若场站 CSV 表示的是 1° × 1° 选址格网，而不是点状场站，可考虑。

当前不建议立即实现：

1. 需要明确场站代表的是点还是面积。
2. 需要构造源网格和目标区域多边形。
3. 对逐小时大规模数据计算成本更高。

## 4. 建议默认策略

短期默认：

```text
--spatial_interp nearest
```

推荐演进：

1. Pipeline B 默认保持 `nearest`，确保已有结果可复现。
2. 对规则经纬度数据源新增可选 `--spatial_interp bilinear`。
3. 对 `cordex_nam12` 初期仅允许 `nearest`；后续再加 `idw`。
4. ERA5Land 稀疏阈值预计算继续固定使用 `bilinear_4point`，因为它只服务阈值侧。

## 5. 代码修改范围

### 5.1 `grid_extreme_signals/station_match.py`

新增统一抽象：

```python
@dataclass
class StationSpatialWeights:
    stations: pd.DataFrame
    idx0: np.ndarray        # (station, point)
    idx1: np.ndarray        # (station, point)
    weight: np.ndarray      # (station, point)
    dist_deg: np.ndarray    # (station,)
    valid: np.ndarray
    grid_kind: str
    method: str
```

新增函数：

```python
match_regular_weighted(grid_lat, grid_lon, stations_df, method="nearest", max_dist=...)
match_2d_weighted(lat2d, lon2d, stations_df, method="nearest", max_dist=...)
gather_to_stations_weighted(arr3d, weights)
```

兼容策略：

1. 保留现有 `StationMatch`、`match_regular`、`match_2d`、`gather_to_stations`。
2. 新函数先服务新参数路径。
3. 稳定后再考虑内部复用，避免一次性重构。

### 5.2 `scripts/station_signals_direct.py`

新增 CLI：

```text
--spatial_interp nearest|bilinear
```

规则：

1. 默认 `nearest`。
2. `regional_bcsd` 和 `china_cmfd_bcsd` 支持 `nearest|bilinear`。
3. `cordex_nam12` 暂时只支持 `nearest`；若传 `bilinear`，明确报错。
4. 输出属性写入：

```text
match_method = nearest | bilinear
match_weight_points = 1 | 4
max_match_dist_deg = ...
```

若使用双线性，还建议输出：

```text
match_idx0(station, point)
match_idx1(station, point)
match_weight(station, point)
```

### 5.3 低资源目标 CF 抽取

`cf_low_resource.compute_station_low_resource(...)` 当前内部最近邻读取目标 CF。

后续建议新增参数：

```python
spatial_interp: str = "nearest"
```

处理方式：

1. `nearest` 沿用当前逻辑。
2. `bilinear` 对目标 CF 文件的规则经纬度网格做四点加权读取。
3. 稀疏 ERA5Land 阈值文件匹配不受影响，仍按 `(lon, lat, type)` 找 station。

## 6. 测试计划

1. 最近邻路径输出与当前结果一致。
2. 规则网格双线性权重和为 1。
3. 经度接缝附近双线性权重正确。
4. 缺测值处理：
   - 若四点都有值，正常加权。
   - 若部分缺测，按有效点重归一。
   - 若全部缺测，输出 NaN 并最终信号置 0。
5. NAM-12 传 `bilinear` 时给出清晰错误。
6. 输出 NetCDF attrs 和权重变量能完整追踪映射方法。
