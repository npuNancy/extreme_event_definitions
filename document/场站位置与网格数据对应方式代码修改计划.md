# 场站位置与网格数据对应方式代码修改计划

## 1. 范围

本计划只处理站点级极端事件判断中的“场站位置 -> 网格数据”对应关系。

纳入范围：

1. Pipeline B 中从气象网格或目标 SSP CF 网格抽取场站时间序列。
2. `regional_bcsd`、`china_cmfd_bcsd` 等规则经纬度网格的最近邻和双线性插值。
3. `cordex_nam12` 的 NAM-12 旋转极网格最近邻匹配。
4. 输出文件中记录实际使用的匹配方法、匹配距离和必要的权重信息。

不纳入范围：

1. 基于 ERA5Land CF 的低资源阈值预计算。
2. ERA5Land 稀疏阈值文件生成时的四点双线性权重。
3. 区域平均、面积加权或保守映射。
4. IDW、克里金、样条等更复杂插值方法的实现。

ERA5Land CF 阈值侧已经有独立计划和实现，本计划不改变该部分。

## 2. 当前行为

当前场站级流程对一个场站使用最近邻网格点获取气象或容量因子数据：

1. `regional_bcsd`、`china_cmfd_bcsd` 等规则经纬度网格使用一维 `lat/lon` 最近邻。
2. `cordex_nam12` 旋转极网格使用二维真实 `lat/lon` 展平后的最近邻。
3. Pipeline B 输出属性记录 `match_method = nearest` 和 `max_match_dist_deg`。
4. 低资源事件中，目标 SSP CF 目前也沿用最近邻读取目标 CF；稀疏 ERA5Land 阈值文件只用于提供阈值和气候态。

## 3. 目标

1. 默认行为保持最近邻，确保已有结果可复现。
2. 对规则经纬度网格增加可选双线性插值。
3. NAM-12 只使用最近邻，并为未来更复杂插值方案预留接口；当前传入其它方法时明确报错。
4. 除 `nearest` 和 `bilinear` 外，其它模式只做占位处理，提示不支持。
5. 输出 NetCDF 必须记录实际使用的场站-网格对应方式，避免结果不可追踪。

## 4. 支持的方法

### 4.1 最近邻

名称：

```text
nearest
```

适用：

1. 所有站点级极端事件。
2. 规则经纬度网格。
3. NAM-12 旋转极二维网格。
4. 目标 SSP CF 的场站抽取。

行为：

1. 规则经纬度网格使用一维 `lat/lon` 最近邻。
2. 经度按文件实际约定归一化，支持 `[0, 360)`、`[-180, 180)` 和 ±180° 接缝。
3. NAM-12 使用二维真实 `lat/lon` 展平后做 KDTree 最近邻。
4. 若匹配距离超过 `max_match_dist_deg`，该站点对应事件信号置 0。

默认：

```text
--spatial_interp nearest
```

### 4.2 双线性插值

名称：

```text
bilinear
```

适用：

1. 规则经纬度网格。
2. 站点级气象变量抽取。
3. 目标 SSP CF 的场站抽取。

不适用：

1. NAM-12 旋转极二维网格。
2. 任意不规则二维网格。
3. ERA5Land CF 阈值预计算。本计划不处理阈值侧。

行为：

1. 对每个场站查找其四周网格点。
2. corner 顺序固定为 `southwest, southeast, northwest, northeast`。
3. 计算四点双线性权重，权重和应为 1。
4. 经度按 360° 环形处理，支持接缝附近场站。
5. 若部分格点缺测，对有效点权重重归一；若四点均缺测，该时间步输出 NaN，后续事件信号置 0。
6. 若场站在网格边界外，退化为边界上的最近可用包围点；仍需记录 `valid=False` 或对应距离状态，由下游掩膜处理。

## 5. 不支持模式占位

CLI 和内部接口可以预留更多取值，但本轮只实现 `nearest` 和 `bilinear`。

以下模式当前不实现：

```text
idw
conservative
kriging
spline
```

处理规则：

1. 用户传入上述模式时，直接抛出 `NotImplementedError` 或 `ValueError`。
2. 报错信息必须说明当前只支持 `nearest` 和 `bilinear`。
3. NAM-12 若传入 `bilinear` 或任何非 `nearest` 方法，也直接报错，并提示 NAM-12 当前只支持最近邻。

## 6. 建议 CLI

### 6.1 Pipeline B

在 `scripts/station_signals_direct.py` 中新增：

```text
--spatial_interp nearest|bilinear
```

默认：

```text
nearest
```

数据源约束：

```text
regional_bcsd      nearest | bilinear
china_cmfd_bcsd    nearest | bilinear
cordex_nam12       nearest only
```

### 6.2 低资源目标 SSP CF

低资源事件使用 ERA5Land 稀疏阈值文件提供 `clim/threshold`，但目标 SSP CF 仍需要从目标 CF 网格抽取到场站。

建议在 `cf_low_resource.compute_station_low_resource(...)` 中新增：

```python
spatial_interp: str = "nearest"
```

行为：

1. `nearest` 沿用当前目标 SSP CF 最近邻读取。
2. `bilinear` 仅对规则经纬度目标 SSP CF 文件启用四点加权读取。
3. 该参数只影响目标 SSP CF 抽取，不影响 ERA5Land 阈值文件。

## 7. 代码修改范围

### 7.1 `grid_extreme_signals/station_match.py`

新增统一的加权匹配结果：

```python
@dataclass
class StationSpatialWeights:
    stations: pd.DataFrame
    idx0: np.ndarray        # (station, point)
    idx1: np.ndarray        # (station, point)
    weight: np.ndarray      # (station, point)
    dist_deg: np.ndarray    # (station,)
    valid: np.ndarray
    grid_kind: str
    method: str
```

新增函数：

```python
match_regular_weighted(grid_lat, grid_lon, stations_df, method="nearest", max_dist=...)
match_2d_weighted(lat2d, lon2d, stations_df, method="nearest", max_dist=...)
gather_to_stations_weighted(arr3d, weights)
```

实现要求：

1. `method="nearest"` 时，`point=1`，权重为 1，并与现有 `match_regular` / `match_2d` 结果一致。
2. `method="bilinear"` 时，只允许规则经纬度网格，`point=4`。
3. `match_2d_weighted(..., method!="nearest")` 直接提示不支持。
4. 保留现有 `StationMatch`、`match_regular`、`match_2d`、`gather_to_stations`，避免一次性重构。

### 7.2 `scripts/station_signals_direct.py`

修改内容：

1. 新增 `--spatial_interp`。
2. `_process_tech(...)` 在首次加载 bundle 后按参数选择匹配方式。
3. `_gather_weather(...)` 支持最近邻或加权抽取。
4. 对 NAM-12 数据源，如果 `--spatial_interp != nearest`，明确报错。
5. 输出 attrs 写入：

```text
match_method = nearest | bilinear
match_weight_points = 1 | 4
max_match_dist_deg = ...
```

若使用双线性，输出额外追踪变量：

```text
match_idx0(station, point)
match_idx1(station, point)
match_weight(station, point)
```

### 7.3 `grid_extreme_signals/cf_low_resource.py`

只改目标 SSP CF 抽取：

1. 新增 `spatial_interp="nearest"` 参数。
2. `nearest` 沿用当前 `_materialize_station_cf(...)`。
3. `bilinear` 新增四点加权读取目标 CF 的实现。
4. 稀疏 ERA5Land 阈值文件匹配逻辑不变。
5. 如果目标 CF 文件不是规则一维 `lat/lon` 网格，则 `bilinear` 报错。

### 7.4 `grid_extreme_signals/station_match.write_station_signals(...)`

输出保持向后兼容：

1. `match_dist_deg(station)` 继续保留。
2. 最近邻时不强制写 `match_idx0/match_idx1/match_weight`。
3. 双线性时写 `point` 维度和三类追踪变量。
4. 全局属性记录：

```text
match_method
match_weight_points
```

## 8. 测试计划

1. 最近邻路径输出与当前结果一致。
2. 规则经纬度双线性权重和为 1。
3. 经度接缝附近双线性权重正确。
4. 双线性抽取结果与手工四点加权结果一致。
5. 部分缺测时按有效点权重重归一。
6. 四点全部缺测时输出 NaN，最终事件信号置 0。
7. NAM-12 使用 `nearest` 正常。
8. NAM-12 传入 `bilinear` 报错，错误信息说明当前只支持最近邻。
9. `idw`、`conservative` 等占位模式报错，错误信息说明当前只支持 `nearest` 和 `bilinear`。
10. 输出 NetCDF attrs 和双线性追踪变量完整。
