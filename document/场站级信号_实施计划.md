# 场站级极端天气信号实施计划（Pipeline B）

> 当前结论：只保留直接场站流程；不再维护先网格后场站流程，也不再生成全网格 `signal_low_resource`。

---

## 1. 输入与目标

1. 场站输入：
   - `stations_SSP1-2.6.csv` → `ssp126`
   - `stations_SSP2-4.5.csv` → `ssp245`
   - `stations_SSP5-6.0.csv` → `ssp585`
   - 列：`year,type,lon,lat,capacity_gw`
2. 场站去重：
   - 同一 `(lon, lat, type)` 跨年份重复时，取最早年份作为 `activation_year`。
3. 输出：
   - `station_signals_{tech}_{model}_{region}_{scenario}_{years}.nc`
   - 维度为 `(time, station)`。
   - 变量为 `signal_<event>(time, station)` 和场站元数据。

---

## 2. Pipeline B 流程

脚本：

```text
scripts/station_signals_direct.py
```

流程：

1. 读取场站 CSV，并按技术类型 `wind/solar` 分组。
2. 用 Natural Earth 国界筛选落在目标国家/区域内的场站。
3. 通过数据源 adapter 加载并标准化目标气象数据。
4. 将气象网格最近邻抽取到场站。
5. 对简单事件调用 `registry.simple_signals(...)`。
6. 对低资源事件读取目标 CF 文件，并使用 ERA5Land 2015-2025 阈值文件判定。
7. 应用 `activation_year` 掩膜和最大匹配距离掩膜。
8. 写出场站级 NetCDF。

---

## 3. 低资源事件

低资源事件 `signal_low_resource` 默认启用。

约定：

1. 低资源使用容量因子 CF 口径：
   - `wind_cf`
   - `solar_cf`
2. 目标模式/SSP 的 CF 只用于计算目标时段滚动资源。
3. 阈值固定来自 ERA5Land 2015-2025 预计算文件。
4. 若目标 CF 文件或阈值文件缺失，该事件写入 `skipped_events` / `skipped_event_reasons`。
5. 光伏仍做夜间剔除。

默认阈值目录：

```text
outputs/low_resource_thresholds/ERA5Land_2015-2025
```

---

## 4. 测试重点

1. 场站筛选和去重后 `activation_year` 正确。
2. 最近邻匹配经度归一化正确，尤其是 `[0, 360)` 区域。
3. 投产前年份信号为 0。
4. 超过 `max_dist` 的场站信号为 0。
5. `signal_low_resource` 不使用目标 SSP 自身 CF 估计阈值。
